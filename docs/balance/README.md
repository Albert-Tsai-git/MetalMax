# 数值平衡记录

平衡原则：不是让各类武器数值相等，而是每种选择都有自己的最优场景、代价与收益匹配，并由遇敌与关卡设计创造使用场景（详见 [sim_latest.md](sim_latest.md) 的压制检查）。

## 工具

- 模拟：Unity 菜单 `Game/批量战斗模拟（平衡）`，或持 unity 锁后 `sh tools/sim.sh`；结果写入 `sim_latest.md`。
- 调数值：`python tools/tune.py 表:ID:列=值 ...`（只改 `UNITY/Data/*.csv`）。

## 第一幕目标与结果（2026-09-27，第 3 轮）

| 指标 | 目标 | 结果 |
|---|---|---|
| 泵站杂兵战（Lv3） | 所有配置可胜，但回合/损耗随配置明显不同 | 胜率均 100%；蚁群最优为火焰，炮台虫为电击，混编为实弹，导弹损耗最低 |
| 铁钳巨蟹（Lv5，满状态） | 克制配置 ≥85%，普通配置约 50%~70%，被克制配置明显吃力 | 电击 96%、全能 93%、导弹 73%、实弹 68%、火焰 35%（巨蟹抗火） |
| 泵站一趟（3 场遇敌 + 巨蟹，不回城） | 有准备 60%~80%，无准备明显偏低 | 电击 79%、导弹 64%、全能 63%、实弹 31%、火焰 16% |
| 压制检查 | 无配置被全面压制 | 通过 |

## 调整记录

| 轮次 | 调整 | 原因 |
|---|---|---|
| 1 | 巨蟹 HP 600→450、防御 40→25、攻击 70→55；夹击威力 150→130、破坏 35→25%；甲壳修复 25→15%；火焰喷射器攻击 18→24；导弹每发 150→100G | 首次模拟巨蟹对所有配置胜率 0%；火焰喷射器被机枪全面压制 |
| 2 | 巨蟹 HP 450→380、回复 15→10%、破坏 25→20%；火焰喷射器 24→30；蚁 HP 40→36 | 巨蟹战超过 30 回合；火焰需能一发击杀蚁才有明显优势 |
| 3 | 泵站一趟遇敌 6→3 场（按走廊长度与遇敌率估算）；炮台虫赏金 60→90 | 对齐实际遇敌期望；用对克制武器打炮台虫应当赚钱 |

同时新增机制：战斗中修理（机械师专长，猎人少量），让步行的机械师在车战中有明确作用。

## 经济曲线（进度模拟，见 [economy_latest.md](economy_latest.md)）

目标：从 Lv1、500G 出发，“升到 Lv5”与“买得起巨蟹克制武器（电击炮）”同步，约 15~20 场野外战斗；火焰喷射器作为第一件升级尽早可得；巨蟹赏金（3000G + 战利品 1000G）支付第二幕大件（重型底盘 6000、V12 3000、导弹 4000）。

| 里程碑 | 调整前（中位场数） | 调整后 |
|---|---|---|
| 可买火焰喷射器 | 14 | 4 |
| 升到 Lv5 | 17 | 17 |
| 可买电击炮 | 56 | 19 |

| 调整 | 原因 |
|---|---|
| 野外改用真实遇敌表（蚁×2、野狗×2、蚁×3、野狗+蚁） | 原先使用内置演示敌人 |
| 装甲修理按损失 SP 计费（每 2 SP 1G） | 原先回满 SP 免费，挨打没有代价 |
| 蚁赏金 20→32、野狗 15→25；电击炮 2200→1500、火焰喷射器 900→700 | 使武器购买与升级进度同步 |
