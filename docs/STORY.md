# 盐海遗讯：故事设定与主线大纲

> 2026-09-27 叙事提案。角色、地名与剧情尚待整体试玩确认；机制条件、数据 ID 与接入事件以 `docs/INTERFACE.md` 正式条款为准。

## 核心故事

内海干涸后，盐层吞没港口，旧公路成为聚落之间仅存的生命线。地下泵网并未彻底停机：它偶尔把淡水送往无人居住的旧区，却让沿线聚落长期配给。主角在修复一辆轻型回收车时收到一段从废弃泵站发出的求救讯号，循线发现发信者是仍在执行旧时代水权协议的自动调度系统。它有维护记录，却没有权力重新决定谁该活下去。

故事的核心抉择是公开泵网的控制权，还是把它交给某一方。重点放在修路、配水、维修和人情债等具体后果；悬赏目标与遗迹探索逐步揭示旧协议的漏洞。

## 世界与历史

- **退潮前**：内海沿岸城市依赖环海泵网调节水位、输送淡水。水权协议把每座城镇的份额写进自动调度系统，原意是防止战时抢水。
- **盐落之年**：能源链断裂，泵网关闭大部分闸门。内海在数十年内退成盐盆；维护站散落荒原，城镇失去互相验证供水账目的能力。
- **现在**：车队运输滤芯、金属和饮水。幸存泵站会按过期人口档案分水。当地人把偶发的泵声叫作“盐海心跳”。

## 地区与势力

| 地区或势力 | 立场与资源 | 矛盾 |
|---|---|---|
| **栈桥镇** | 起始据点；旧公路尽头的修车与换水集市 | 维修能力充足，却没有稳定水源 |
| **井务联合会** | 控制仍可用的井、滤芯和水车 | 主张集中调度，担心公开泵网后发生争夺 |
| **路灯车队** | 经营盐盆上的护送与补给线路 | 想保留小聚落用水份额，不信任城镇独占协议 |
| **封闸守备** | 占据旧泵网主控站的遗民组织 | 认为改变旧协议会毁掉仅存的安全余量 |
| **白盐带** | 暴露的海床、报废管线和沉船 | 不是一个势力；风暴、盐蚀和失控设备使路线随季节变化 |

各方都有可理解的利益。井务联合会真能救急，也会拿配给控制交易；封闸守备掌握旧档案，也曾隐瞒错误名单。

## 主角团

| 人物 | 人设与弧线 | 视觉与语气 |
|---|---|---|
| **阿砾**（猎人，玩家角色提案） | 栈桥镇出身的年轻回收驾驶员；起初只想还清修车债，后来必须决定是否承担公开真相后的责任。性格能由对话选择呈现，但关键行动不写成固定的“天选者”。 | 防尘披肩、旧驾驶镜；说话简短，习惯先问路况与价钱。 |
| **棠榆**（机械师） | 曾给井务联合会修过阀门，因拒绝篡改故障记录离开；她能读懂泵网，但需要学会把解释权交给居民。 | 工具卷、滤芯包、双层手套；说话精确，偶尔冷幽默。 |
| **岚钉**（后期伙伴提案） | 路灯车队护卫，擅长徒步探路；曾因一次错误护送选择失去同伴，抗拒把“多数人获益”当成轻易的借口。 | 路标布条、短甲；直言，先护人再谈原则。 |

首个可玩切片只需要阿砾与棠榆。岚钉可先作为 NPC 出场，加入队伍的时机不预设机制实现。

| 人物 | 身份 | 剧情作用 |
|---|---|---|

| **沈规** | 井务联合会配水员 | 坚信集中管理能减少伤亡；愿意交出物资换取独占控制密钥。 |
| **苏灯** | 路灯车队领队 | 用手绘地图记录偏远聚落与旧档案的出入；要求让所有聚落先看见真实账本。 |
| **闸卫七号** | 主控站的旧时代维护机 | 会执行维修命令和过期协议，无法判断今日居民的需求；不写成有善恶意志的最终反派。 |

## 主线大纲

### 第一幕：欠账与信号

阿砾拿到一辆勉强能跑的轻型车，与棠榆调查栈桥镇断续收到的泵站呼叫。荒野委托让玩家认识补给成本和沿路居民；击退盘踞滤站的铁钳巨蟹后取得仍可读取的维护日志。日志显示泵网持续供水，只是目的地与现居人口不符。

**首个切片落点**：栈桥镇、白盐带一段路、废弃泵站短迷宫、铁钳巨蟹和“信号并非求救”的揭示。切片结束时保留下一站方向，不要求实现全局阵营分支。

### 第二幕：账本上的空城

队伍沿旧管线寻找校准点，见到被系统判定“无人”的活聚落与继续领水的空城遗址。井务联合会提供集中修复方案；路灯车队带来人口和路线证据；封闸守备警告主控一旦重算，低储量地区可能先断水。阿砾一行把口述见闻与维护日志逐一核对，找出旧协议中无法自动更改的分配锁。

### 第三幕：谁来开闸

主控站面临风暴损坏，必须先修复供能与滤芯，再讨论控制权。最终选择提案有三种表达方向：由联合会接管并接受监督；公开账本、由聚落代表共同调度；保留低风险的临时配给，同时拆分主控权。每种方案都应有代价、可追责的人和可见的后续供水变化。具体分支条件与结算数值交由机制侧设计。

## 支线与文本基调

- **路标委托**：给失踪水车补绘一段旧路。完成后得知它绕路是为小聚落送水，并非私吞货物。
- **空井的回声**：一台旧广播仍播报已经消失的居民姓名；玩家找回名单，使邻镇能证明自己的配水资格。
- **铁钳巨蟹悬赏**：先让水车恢复通行，再由曲婆拿巨蟹外壳修补车库屋顶；报酬与世界变化都可见。
- **对话风格**：短句、具体物件与行动，少用抽象口号。幽默来自修车账、过期标语与荒原生活，不拿受灾者取笑。

## 表现提示

泵网遗迹以盐白混凝土、褪色水位刻线和少量仍亮的橘色维护灯形成统一识别。栈桥镇的灯光偏暖，白盐带留大面积亮地与远处黑色管架；越接近主控站，机械脉冲与远距离水声越明显。具体音频触发和事件名等待接口条款确认。
